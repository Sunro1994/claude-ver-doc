# Plugin — 페르소나별 추천

Plugin = skill + MCP + agent를 묶은 배포 단위. 공식·커뮤니티 배포.
공통 4개 + 페르소나 1-2개로 최소 구성이 완결된다.

## 공통 필수

- `token-optimizer` — 세션 헬스·비용 관리
- `superpowers` — brainstorming, writing-plans, TDD 등 사고·구현 코어
- `deep-research` — 다중 소스 리서치·검증
- `report-writer` — 결과물 문서화

## 영어 마케터 (귀 악세서리 브랜드 CEO)

공통 4개면 충분. 추가는 CRM 통합 필요 시 `hubspot` 계열 검토.

## 신소재 연구 박사과정

- `understand-anything` — 지식 그래프, 논문·노트 관계 시각화

## 채권 금융

- 공통 4개면 충분. Excel 무거운 사용 시 Microsoft 365 MCP.

## 비자 컨설팅

- 공통 4개면 충분. 케이스 DB가 커지면 `understand-anything`.

## Plugin vs Skill vs MCP

| 개념 | 역할 | 배포 단위 |
|---|---|---|
| Skill | 프롬프트·워크플로우 | 파일 |
| MCP | 외부 도구 연결 | 서버 |
| Plugin | 위 둘 + agent 번들 | 마켓플레이스 |
