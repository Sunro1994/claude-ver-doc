# 모델·토큰·비용 관리

비용의 90%는 모델 선택과 컨텍스트 크기에서 결정된다.

## 모델 선택 가이드

| 모델 | 언제 | 예 |
|---|---|---|
| **Opus** | 신뢰성 최우선, 복잡 판단 | 아키텍처 설계, 코드 리뷰, 다단계 sub-agent |
| **Sonnet** | 균형 (기본값) | 일반 코딩, 문서 작성, 리팩토링 |
| **Haiku** | 짧은 반복 작업 | 요약, 분류, 태깅 |

**원칙**: 서브에이전트는 Opus 고정. 파이프라인 실패의 downstream 비용이 토큰비보다 크다.

## Prompt caching

Anthropic API에서 반복 프롬프트를 5분간 캐시 유지.

- 시스템 프롬프트·큰 컨텍스트 앞부분에 `cache_control` 지정
- 캐시 히트 시 입력 토큰비 90% 감액
- 미스 시 정상비 (5분 이상 대기하면 미스)
- **주의**: 세션이 5분 이상 idle이면 다음 요청은 미스 → 300초 sleep 후 뭔가 하지 말고 270초 or 1200초로 선택

## 컨텍스트 관리

- `/clear` — 새 대화 시작 (컨텍스트 초기화)
- 긴 세션은 자동 압축되며 사실 기억이 흐려짐 → 중요한 건 memory에 저장
- `/token-optimizer:quick` — 현재 컨텍스트 헬스 10초 체크
- `/token-optimizer:token-optimizer` — 유령 토큰 사냥 (설정·hook·skill 감사)

## 세션 재개 vs 새 세션

- **재개**: 이전 맥락 유지 필요 시. 압축·요약 손실 감수
- **새 세션 + /clear**: 새 태스크, 이전 컨텍스트 오염 없이 시작

## 비용 감시 팁

- 서브에이전트 남발 금지 — Task tool 1회 = 별도 세션
- 대문서 fetch → memory 저장 후 재사용
- 반복 프롬프트는 skill 화 → 재작성 방지

## 실전: 페르소나별 티어 예산

| 연구자 | Sonnet | 논문 서베이, 리뷰 |

| 비자 컨설팅 | Opus | 오정보가 클라이언트 손해 |
