# Skill — 페르소나별 추천

Skill = 재사용 가능한 프로프트·워크플로우 묶음. `/skill-name`으로 호출.

## 공통 필수

- `superpowers:brainstorming` — 창작 시작점. 요구·의도 발산
- `superpowers:writing-plans` — 다단계 작업의 계획서
- `report-writer` — 결과물 문서화

## 영어 마케터 (귀 악세서리 브랜드 CEO)

- `superpowers:brainstorming` — 캠페인 컨셉 발산
- `deep-research` — 경쟁사·트렌드·인플루언서 리서치
- `report-writer` — 주간 마케팅 리포트
- `superpowers:writing-plans` — 캠페인 실행 계획서

## 신소재 연구 박사과정

- `deep-research` — 논문 서베이, cross-source fact-check
- `understand-anything:understand-knowledge` — 논문·노트 지식 그래프
- `graphify` — 관련 논문 관계 시각화
- `report-writer` — 실험 로그, 학회 발표 초안

## 채권 금융

- `deep-research` — 시장 동향, 발행사 신용
- `report-writer` — 딜 브리프, 시황 보고
- `superpowers:brainstorming` — 헤지·차익 전략 발산

## 비자 컨설팅

- `deep-research` — 판례·정책 검색
- `report-writer` — 케이스 요약, 클라이언트 리포트
- `superpowers:writing-plans` — 서류 준비 체크리스트

## 나만의 skill 만들기

3번 이상 반복하는 프롬프트는 skill 화 대상.
`~/.claude/skills/{name}/SKILL.md`에 프론트매터(name, description) + 지침을 작성.
